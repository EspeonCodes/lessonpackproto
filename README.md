# Lesson Pack Prototype
**This is a first iteration of my degree thesis project.**

This is a simulation of horizontal projectile motion under a homogenous, constant field of graviity. Air resistance is considered negligible for this example. 

The user can manipulate the projectile's starting height and horizontal velocity with the sliders on the sidebar, then commence the simulation in a variety of ways:
1. The PLAY button starts the simulation at the standard rate. 
2. The SLO-MO button starts the simulation at a slower rate.
3. The BACK and FORWARD buttons pause the simulation and move the projectile forward or backward in time by a preset value.

To stop or reset the simulation, the user can press the PAUSE or RESET buttons, respectively.

### Intent
My intention behind this project is to create an accessible, student-centered lesson that game-ifies the process using stages, point scoring and (possibly) unlockable customization. 
Besides the topic of Horizontal Projectile Motion, this app should be used to teach variable control through the restriction of user/student options.
